# MCANet

Qualitative comparison figures for *MCANet: Multi-Center Contrastive Alignment Network for Cross-Domain Polyp Segmentation* are provided in [Results.zip](Results.zip).

- `ETIS-Larib.pdf` shows examples of adaptation from ETIS-Larib to EndoScene and Kvasir-SEG.
- `EndoTect.pdf` shows examples of adaptation from EndoTect to EndoScene and Kvasir-SEG.

These PDFs reproduce the displayed comparison figures. The MCANet contours were smoothed for display. In the fourth row of the EndoTect figure, the displayed MCANet contour was also locally edited. The numerical evaluation uses the original predictions.
